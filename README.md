# 🚀 Login Page

A sleek, modern, and fully responsive authentication portal designed for a seamless user experience. Built with clean HTML5, structured CSS, and structured with accessibility in mind.

---

## ✨ Features

* **Modern UI/UX:** Clean, minimalist design focused on a centered card layout with smooth interactive states.
* **Fully Responsive:** Adapts seamlessly across various screen sizes (mobile, tablet, desktop).
* **Accessible & Semantic:** Uses proper HTML5 elements, associated `<label>` elements, and smart input attributes (`autocomplete`, `required`).
* **Optimized CSS:** Written with clean structure, following best practices and methodology.

---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 / Modern CSS (Flexbox, Nesting)
* **Fonts:** Google Fonts (*Montserrat*)
* **Assets:** Custom SVG icons
